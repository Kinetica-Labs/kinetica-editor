# Конституция разработки Kinetica

Редактор — кисть, плагины — картины. Мы строим так, чтобы автор — человек или ИИ-агент — за минуты получил
законченную работающую вещь, правил её с откликом меньше секунды без страха (всё отменяется) и не потерял
её в следующем выпуске. Эти три переживания удерживают авторов сильнее любой функции. Статьи ниже — выжимка
исследования [docs/design/plugin-sdk-research.md](design/plugin-sdk-research.md): психология разработчиков,
экосистемы плагинов, архитектура, математика, физика симуляторов (106 источников). Почему устроено так, как
устроено сейчас, — [docs/design/foundations.md](design/foundations.md).

Каждая статья проверяется. Статья без проверки — пожелание, а не статья. Изменение кода, нарушающее
статью, либо исправляется, либо идёт вместе с поправкой конституции (коммит «Конституция: …» с причиной).

## I. Мир

1. **Одна физика — за контрактом.** Твёрдые тела считает готовый движок за `PhysicsWorld`. Своих решателей,
   газа, жидкостей, ткани, мягких тел нет даже выключенными.
   *Проверка:* шаг абляции в CI; `box3d.h` только в `plugins/physics/box3d/`.
2. **Наблюдаемость — устройство кода, а не дисциплина.** Управление робота получает только показания
   датчиков. Истина физики доступна только роли проверки (`lab`), и путь к ней задан типом аргумента:
   у контроллера просто нет ссылки на истину.
   *Проверка:* тест соответствия — контроллер по первому рецепту не может прочитать истинную позу.
3. **Детерминизм по построению.** Фиксированный шаг; часы мира — целые наносекунды; шум — из генератора
   хоста с ключом (сцена, плагин, объект, стадия), так что новый плагин не сдвигает чужой шум; всё, что
   влияет на будущее, сериализуемо. Запрещены настенные часы, `std::*_distribution`, обход `unordered_*`,
   fast-math.
   *Проверка:* повтор журнала даёт тот же хэш сцены; CI сравнивает хэш GCC и MSVC с плагином и без.
4. **Единицы — данные.** У каждого поля — единица UCUM (`m`, `kPa`, `Hz`) и размерность; внутри СИ;
   намеренное смешение — только явно и с причиной. Подпись для человека отдельна от кода единицы.
   *Проверка:* размерность сверяется при загрузке схемы и таблиц; суффиксы ключей сверяются с объявленной единицей.

## II. Действие

5. **API = UI.** Всякое действие — операция со схемой. Кнопки без операции не бывает. Встроенное и
   стороннее ходят через один публичный API: у плагина нет потолка ниже встроенного, и нет хода во
   внутренности.
   *Проверка:* самотест обходит каждую кнопку — ровно одна операция из `ops_list` и её строка Python.
6. **Каждое действие — строка Python и шаг отмены своего источника.** Правка — одна транзакция с
   `origin`; Ctrl+Z снимает свои правки; журнал JSON lines только дописывается. Команда плагина не
   мутирует сцену сама: она составляет команды ядра или возвращает diff, обратную правку строит ядро.
   *Проверка:* `execute → undo` возвращает хэш; эхо Python, выполненное заново, даёт ту же сцену.
7. **Схема-данные — единственный источник.** Поле `{name, type, unit, min, max, soft_min, soft_max, step,
   default, label, help}` порождает форму, проверку, строку `.kscene`, JSON Schema, схему MCP, `.pyi`,
   справочник. Ручных дублей нет. Значение вне жёсткого диапазона отвергается с именем поля и границей,
   а не прижимается молча; мягкий диапазон ограничивает только ползунок.
   *Проверка:* ни одной операции с открытой схемой; обёртки Python генерируются из `ops_list`.
8. **Композиция, а не иерархия; модели — данные.** Датчик = зонд физики + сигнальная цепочка паспорта +
   выход; вид — рецепт, модель — строка таблицы в `data/`. Числа моделей не живут в коде.
   *Проверка:* новая модель датчика добавляется строкой CSV без пересборки.

## III. Автор

9. **Законченная вещь за 5 минут.** Мастер «Плагины ▸ Новый…» в окне, плагин из одного файла без
   манифеста и сборки, кнопка появляется сразу.
   *Проверка:* перед каждым мажорным выпуском — медиана по ≥5 слепым новичкам (люди и `--agent-eval`),
   время от создания до первого успешного вызова команды плагина по журналу.
10. **Петля правки: Python ≤ 1 с, C++ ≤ 10 с с прогнозом.** Сцена и выделение переживают перезагрузку.
    Перезагрузка — перезапуск процесса или замена модуля с `save_state`/`load_state`, а не подмена функций.
    *Проверка:* время каждой перезагрузки в тосте и в самотесте.
11. **Ошибка указывает на код автора.** Файл:строка, «ожидалось / получено», одна подсказка.
    *Проверка:* корпус ≥20 типичных ошибок новичка с эталонными сообщениями.
12. **Сбой плагина не роняет редактор.** Процесс плагина — под супервизором: баннер, отключение, кнопка
    «перезагрузить», журнал цел. Встраиваемый модуль — полное доверие, и это сказано прямо при установке.
    *Проверка:* фаззинг падающими и зависающими плагинами.
13. **Стабильность обещана и видна.** Интерфейсы по ID (`ke.component/1`) неизменны после выпуска; новое
    сначала `draft`, неопубликуемое; ломающее изменение объявляется заранее, с миграцией; версия схемы у
    каждой операции и функция обновления аргументов для повтора старого журнала.
    *Проверка:* CI собирает все рецепты и плагины галереи на каждом PR.
14. **Документация — запускаемые примеры.** Рецепты по 3–10 вызовов с отметкой «проверено на версии X»;
    справочник генерируется; `llms.txt` и `AGENTS.md` — для агентов.
    *Проверка:* рецепты — тесты CI.
15. **Признание без очков.** Имя автора на карточке, число использований, лестница качества
    Bronze → Platinum. Никаких бейджей за количество: ожидаемая награда подрывает внутреннюю мотивацию.

## IV. Ремесло

16. **Меньше кода за счёт структуры.** Один факт — в одном месте. Число строк до и после рефакторинга —
    в его коммите. Каждый файл начинается с абзаца: что в нём и где остальное.
17. **Контракт, документ и тесты меняются одним коммитом** (`docs/contracts/*.md`).
18. **Пороги — после замеров.** Числа чужих стендов — гипотезы. Прежде чем закреплять пороги
    статей 10 и 12, мерим на целевой машине: круг TCP JSON lines, шаг Box3D, мост через общую память.
19. **Честный отчёт.** Непроверенное помечено как непроверенное; тест, который не прошёл, назван с выводом;
    пропущенный шаг назван.

## Путь

1. **`Field` — данные.** Единица UCUM и размерность; JSON Schema 2020-12 и строгая схема MCP вместо
   открытой; `origin` и версия схемы в журнале; ключи паспортов в единицах UCUM.
2. **Из схемы — всё.** `FieldForm` — рендерер `Field`, а не второй API; кнопки и меню — из реестра;
   обёртки Python — из `ops_list`.
3. **Плагин-процесс и первые пять минут.** Пакет `kinetica` для плагинов: `@command`, `field`; супервизор,
   перезапуск по сохранению, баннер ошибки с файлом и строкой, рукопожатие и токен; мастер
   «Плагины ▸ Новый…»; `kinetica validate`.
4. **Фазы и права.** `control_tick(readings, commands)`, `pre_substep(Actuate&)`,
   `post_substep(const ProbeView&)`, `verify(const Truth&)` только у роли `lab`; счётчиковый генератор
   шума; контракт состояния.
5. **Соответствие и рецепты.** Тесты законов (отмена, повтор, Пуск/Стоп ×10, единицы, наблюдаемость),
   уровни строгости, рецепты в CI, `llms.txt`, `AGENTS.md`, замер первых пяти минут.
6. **Встраиваемые C-плагины** — со вторым движком физики: дескриптор `ke_plugin_entry` (`struct_size`,
   ABI, `real_size`), интерфейсы по ID, пометки потоков `[main-thread]` / `[sim-thread]`.
