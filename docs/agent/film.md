# Съёмка: инженер, учитель и режиссёр сразу

Зритель видит редактор, ваши вызовы в консоли и карточку шага внизу вида. Свет студии — `narration_stage`, один раз до
сборки.

Ритм каждого шага:

1. `narration_say {text, title, target}` — карточка: `title` — одно-два слова (Основание, Плечо), `text` — одна фраза
   для зрителя, что и зачем, без номеров деталей; `target` — деталь: она светится, камера подлетает к ней; 0 — общий план.
2. Сам вызов — одна деталь за вызов, чтобы зритель видел, как робот растёт.
3. Главной детали — `formula_callout {latex, target}`: короткая формула с числом и единицей
   (`\tau = m g L \approx 21\,\mathrm{N\,m}`); `target` может быть суставом — линия придёт к его оси. Не больше пяти на
   робота; длинную мысль — двумя формулами или карточкой.
4. Проверка — как в руководстве (`sim_play`, `sim_measure`), её число — в следующую карточку.

Камера ведётся сама; `narration_camera {on: false}` — выключить. Свой кадр: `view_look {eye, target, glide, orbit}` —
перелёт за `glide` секунд и облёт вокруг цели `orbit` градусов в секунду.

Рука за целью: `assembly_path {goal, points, turns, speed, loop, smooth}` — кубик цели идёт по траектории, рука за ним
по обратной кинематике; точки проверьте заранее `assembly_can_reach`. Повернуть схват, как повёрнута цель, может только
рука с шестью суставами (три — в запястье); с тремя — только точка.
